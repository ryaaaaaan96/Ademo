# 2026-10-24：窗口菜单与左栏精简

取消会话内容区单独的“浮动／停靠到工作台”菜单行。停靠标题右键可浮动，Windows 浮窗系统标题栏菜单可停靠（右键标题或 Alt+Space），同时保留系统三按钮、拖动停靠和内容区右键停靠后备入口。原生菜单命令退出回调后再切换窗口归属，重复打开菜单不重复添加条目，重建窗口句柄后可再次使用。

主站左侧按会话连接、设备与参数、数据操作、自动轮询分为浅色卡片，统一标题、边距和紧凑按钮。设备／分组标签同行显示，保留左栏独立滚动、调宽、收起与参数主体布局。轮询摘要明确“下次启动”范围及周期；错误和操作提示继续显示。连接控件仍通过 SDK13 插槽注入，协议逻辑与窗口生命周期保持既有边界。
