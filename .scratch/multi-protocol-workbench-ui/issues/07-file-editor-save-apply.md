# UI07：在独立文件页编辑、保存并应用参数配置

Status: ready-for-agent
Stage: RTU 新界面
Blocked by: [UI05](05-inline-pending-value-write.md)

依据：[界面规格](../spec.md)、[综合实施索引](../implementation-plan.md)、[已批准拆分](../ticket-breakdown-draft.md)。复用已验收的旧 01–12 与 [Qt/LLVM-MinGW 工具链](../../multi-protocol-debugger/toolchain-environment.md)，不重做协议或传输基线。

## What to build

 每个调试窗口可进入文件编辑页，明确看到设备与文件，编辑/新建后保存或另存，再由用户显式加载/应用到目标设备。

- [ ] 本切片先用 Modbus 主站参数定义完成整条流程；提供插件承载入口，其他角色可复用编辑基础。
- [ ] 编辑、打开文件、保存、另存均不隐式发送设置或替换运行内容；只有明确应用且校验成功才更新目标。
- [ ] 切换设备、关闭、覆盖/重载时处理文件草稿与待提交值，失败保留原内容，其他设备/会话不受影响。
- [ ] 正式参数文件版本与绑定规则可往返，编辑界面无需用户手写 JSON 才能完成基本配置。

**覆盖新规格故事：** 21、43–52。

## 验证方式

沿用已确认的调试会话公开入口及可控传输、时钟，并补充本切片真实 Qt 界面/QML 操作验收。观察用户可见状态与同一会话的发送、数据、文件及记录，不依赖私有容器或精确像素。执行相关定向回归和必要 Debug/Release 验证，附实际环境、截图及未覆盖条件。
