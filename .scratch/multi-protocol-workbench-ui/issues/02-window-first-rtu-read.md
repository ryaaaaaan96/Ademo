# UI02：在新的调试窗口完成一次 RTU 读取

Status: ready-for-agent
Stage: RTU 新界面
Blocked by: [UI01](01-prototype-layout-and-flow.md)

依据：[界面规格](../spec.md)、[综合实施索引](../implementation-plan.md)、[已批准拆分](../ticket-breakdown-draft.md)。复用已验收的旧 01–12 与 [Qt/LLVM-MinGW 工具链](../../multi-protocol-debugger/toolchain-environment.md)，不重做协议或传输基线。

## What to build

 用户新建 RTU 主站会话、配置端点和设备，在正式调试窗口的通用参数表完成一次读取，并看到结果及该会话的基本通信记录。

- [ ] 必要的公开参数/选择访问和视图挂载能力先在本切片内补齐，再接真实会话、协议及传输路径；不以模拟业务替代。
- [ ] 框架模板由 Modbus 插件提供显示与操作内容，主窗口不写入 Modbus 组帧逻辑。
- [ ] 新窗口具备简明启停状态和独立连接配置入口；停止行为、端点释放及首次读取保持已有语义。
- [ ] 旧视图可经兼容入口继续使用，迁移中保持既有回归通过。

**覆盖新规格故事：** 2、16、18、19、24、35、36、68。

## 验证方式

沿用已确认的调试会话公开入口及可控传输、时钟，并补充本切片真实 Qt 界面/QML 操作验收。观察用户可见状态与同一会话的发送、数据、文件及记录，不依赖私有容器或精确像素。执行相关定向回归和必要 Debug/Release 验证，附实际环境、截图及未覆盖条件。
