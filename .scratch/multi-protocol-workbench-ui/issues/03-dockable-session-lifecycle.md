# UI03：同时运行并管理多个可停靠调试窗口

Status: ready-for-agent
Stage: RTU 新界面
Blocked by: [UI02](02-window-first-rtu-read.md)

依据：[界面规格](../spec.md)、[综合实施索引](../implementation-plan.md)、[已批准拆分](../ticket-breakdown-draft.md)。复用已验收的旧 01–12 与 [Qt/LLVM-MinGW 工具链](../../multi-protocol-debugger/toolchain-environment.md)，不重做协议或传输基线。

## What to build

 创建同协议多个会话，在会话→设备导航中定位窗口，窗口可平铺、浮动、重新停靠，底部基本记录随所属窗口移动。

- [ ] 一个窗口对应一个会话，窗口内可添加/选择设备；显示上下文与运行状态不串用。
- [ ] 移动、最小化、折叠、页面和设备选择变化均不停止通信。
- [ ] 关闭停止对应会话，保留配置，重新打开后不自动通信；未保存提示取消时保留原状态。
- [ ] 先验证已有修改保护；后续 UI05/07/08 各自接入新增待提交或文件状态，最终由 UI13 组合验证。

**覆盖新规格故事：** 1、3–13、17、63。

## 验证方式

沿用已确认的调试会话公开入口及可控传输、时钟，并补充本切片真实 Qt 界面/QML 操作验收。观察用户可见状态与同一会话的发送、数据、文件及记录，不依赖私有容器或精确像素。执行相关定向回归和必要 Debug/Release 验证，附实际环境、截图及未覆盖条件。
