## What to build

 保存会话、设备、参数/从站文件引用、轮询配置及窗口布局，再恢复为相同调试安排，所有会话保持停止。

- [x] 保存位置、大小、停靠状态；支持恢复布局，不能把丢失外部文件用内嵌模拟值偷偷兜底。
- [x] 保留未知插件身份和配置；缺失/不兼容插件只影响相关能力，修复后可恢复。
- [x] 覆盖工作区替换期间的未保存文件、模拟值和待提交状态，以及用户取消时保留当前内容。
- [x] 此任务不依赖 UI09 的记录面板呈现，也不要求把尚未确认的曲线窗口布局全部持久化。

**覆盖新规格故事：** 14、15、20、23、44、49、51、52。

## 验证方式

沿用已确认的调试会话公开入口及可控传输、时钟，并补充本切片真实 Qt 界面/QML 操作验收。观察用户可见状态与同一会话的发送、数据、文件及记录，不依赖私有容器或精确像素。执行相关定向回归和必要 Debug/Release 验证，附实际环境、截图及未覆盖条件。
