## What to build

 为设备加载参数 JSON，插件生成分组和参数行；有名称显示名称，无名称显示寄存器地址；无具名配置时可按数据区、起址、数量生成参数并实际读取。

- [ ] 明确正式参数定义、现有从站数据和工作区引用的关系及兼容策略，不能直接采用原型格式。
- [ ] 列、类型/单位/说明和分组来自插件解释，未分组参数进入默认组。
- [ ] 通过明确的加载/应用入口选择目标；无效配置保留原有效内容，不能在此切片偷偷加入“保存即应用”。
- [ ] 只实现本流程必要的读取与参数声明；编辑和保存放在 UI07，其他协议产品实现不提前。

**覆盖新规格故事：** 20、22、24–28、65。

沿用已确认的调试会话公开入口及可控传输、时钟，并补充本切片真实 Qt 界面/QML 操作验收。观察用户可见状态与同一会话的发送、数据、文件及记录，不依赖私有容器或精确像素。执行相关定向回归和必要 Debug/Release 验证，附实际环境、截图及未覆盖条件。
