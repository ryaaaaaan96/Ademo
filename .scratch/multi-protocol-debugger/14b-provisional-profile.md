## 范围与已确认项

- 仅14B：正式CAN后端 → UPP重组/CRC/字段解析 → 插件视图 → 全部分帧回溯；沿用14A和现有Widgets工作台。
- 全部CAN适用功能：0x20/0x21/0x22/0x23/0x26/0x27/0x28及0xA0/0xA1/0xA2/0xA3/0xA6/0xA7/0xA8异常。被动观察写请求不等于执行写入。以太网专用0x24/0x29/0x30/0x31不扩入CAN。
- 当前Word修订整理版本作为依据；设备身份取UPP报文地址，CAN ID是传输来源，不强制两者相等。标准/扩展经典数据帧均接收；远程/错误/FD帧保留原始证据，不当作UPP字节。
- CRC使用CRC-16/MODBUS，覆盖CRC之前的完整ADU，低字节先传；报文不允许交错。未知模型数据保留字节、模型号、偏移和声明长度，不虚构工程值。
- 独立软件样例源可扩展UPP样例，但产品不发送UPP，不创建虚假调试操作。旧15与TCP不启动。

## 暂定选择

| 项目 | 本轮默认规则及失败行为 |
| --- | --- |
| 长度 | 1字节0x00表示256；其余值为完整ADU长度，最短7。配置/代码中集中表达，保留规则版本标识 |
| 分帧 | 同一报文所有片使用相同CAN ID和标准/扩展格式；非末片8字节，末片实际剩余字节，无填充；CRC允许跨片 |
| 重组 | 一个会话当前只重组一条报文；异ID/格式插入中止旧报文并记录错误，不把它们拼接。续片出现0x50不重新判首帧。空闲时只从CAN帧边界识别合法固定块，失败保留来源；不承诺无序号协议可自动纠正所有丢重帧 |
| 超时 | 片间默认100ms、整包默认1000ms，可在协议配置修改；超时/断线/停止清除重组与关联状态，保留失败来源；有界缓存 |
| 地址 | 请求与响应固定块均表示从机设备；CAN ID可不等于地址，不作为PDU寻址替代 |
| 方向 | 传输rx不等于协议response。提供明确的请求/响应观察模式；自动模式仅在结构/上下文唯一时分类，歧义标记未确定，保留字节，不悄悄猜测。可按现有配置能力提供方向选择，不新增路由框架 |
| 序号 | 原样显示8位序号，不因跳号丢弃旁路观测。关联键至少含设备、序号、功能，要求唯一且有界/超时，重复/回绕不能错误复用旧请求。缺请求的0x21响应保留数据并标记地址上下文未知 |
| 异常 | 异常码按2字节大端；允许仅异常码或再带2字节模型+2字节偏移，其余长度明确报错；不复制固定块差错码 |
| 多字节字段 | 模型号、偏移、长度、子序号按大端字段表；CRC仍小端。0x20协议号保留原4字节，不按AA20注释反转 |
| 0x23 | 字段表优先：请求增量类型1B+子序号2B；响应时标类型1B+增量类型1B+单元计数/后续位1B+子序号2B+单元列表。单元长度按字节；SOE变化位按bit0至bit7，CP56Time2a按标准7字节顺序；类型信息不足时不把任意测点原始数据猜成SOE |
| 0x27/0x28 | 0x27所有单元均按各自声明长度取数据；0x28按字段表分别解析读取与设置列表，样例长度按实际结构生成。只观察，不裁定设备实际读写执行顺序 |

这些选择必须在操作说明/视图中可发现；记录中标明暂定规则及软件样例来源。后续可按实际协议修改，不能把本轮自生成样例写成协议方认可向量或硬件互通。
