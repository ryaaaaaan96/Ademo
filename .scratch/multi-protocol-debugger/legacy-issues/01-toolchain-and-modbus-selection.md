# 01 固定工具链并选择满足统一 I/O 的 Modbus 实现

Status: ready-for-agent
Stage: RTU
Dependencies: 无

## 目标

为 RTU 第一阶段提供可复现的构建组合与协议实现路径，避免选用自行占有串口的完整协议栈破坏统一传输和记录。依据：[架构](../architecture.md)、[接口契约](../interface-contracts.md)、[ADR 0002](../../../docs/adr/0002-shared-transport-and-recording.md)。

## 工作范围

- 只读核验现有 Qt、编译器、CMake 和串口联调条件；区分已安装与待安装，不把不存在的环境写成可用。
- 开发环境使用 VS Code。通过 CMake 命令行提供可复现的配置、构建和测试流程，并说明 VS Code 使用入口；不依赖 Qt Creator 工程设置。
- 选择 Windows x64 的 Qt 6、编译器、CMake 和 C++ 版本组合，记录依赖获取及插件配套构建要求。
- 依据官方文档/源码比较自有 RTU/PDU 实现与可注入外部 I/O 的候选实现，覆盖主从、八个功能码、异常响应、RTU 时序与原始记录入口；不重新引入独占 I/O 的 QModbus 完整栈作为默认方案。
- 核验拟选依赖的分发要求，记录版本、来源、采用理由及未解决限制；最小验证产物单独存放，不搭建 TCP 产品功能。
