# 03 实现串口通道与统一原始记录入口

Status: needs-triage
Stage: RTU
Dependencies: 02

## 目标

通过传输插件提供不理解 Modbus 的串口收发，协议输入与输出都经过统一记录入口。依据：[接口契约](../interface-contracts.md)、[ADR 0001](../../../docs/adr/0001-explicit-protocol-transport-support.md)。

## 工作范围

- 异步打开、发送和关闭串口，配置端口及串口参数，报告实际传输能力和错误。
- 管理端口独占、连接代次、有界发送队列和部分写入；发送提交与最终本地发送结果分开。
- 接收单元保留原始字节、时间和来源身份，不以一次读取为一帧，不在后端实现 Modbus 解析。
- 通过可控测试 Adapter 验证错误和分块，再用实际或虚拟串口验证真实 Qt 路径。

## 验收条件

- [ ] 同一串口被重复占用时明确拒绝，不影响其他端口会话。
- [ ] 多次读取、部分写入、队列满及拔出/关闭均有可关联结果；每次接受的发送只产生一次最终本地结果。
- [ ] 原始输入先获得统一记录身份再进入协议，解析失败仍保留记录路径。
- [ ] 停止后释放端口；旧连接回调不归入新操作。
- [ ] 报告实际可观察时间精度与后端限制，不宣称获得未提供的逐字节硬件时间戳。

## 验证证据

保留端口拓扑、串口参数和测试记录；测试驱动输入分块及故障，不依赖私有缓冲区内容断言。
