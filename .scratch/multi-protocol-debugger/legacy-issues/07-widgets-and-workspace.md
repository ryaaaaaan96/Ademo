# 07 实现 Widgets 工作台、Modbus 视图和工作区

Status: needs-triage
Stage: RTU
Dependencies: 04、05、06

## 目标

操作人员可配置并运行多个 RTU 会话、读写或模拟设备、回溯异常并保存工作区。通用工作台与 Modbus 专用视图保持分离。依据：[架构](../architecture.md)、[接口契约](../interface-contracts.md)。

## 工作范围

- 工作台提供会话列表、启动/停止、通用报文列表、操作结果和回溯入口；按批次刷新，保留简单状态。
- Modbus 插件提供寄存器/位数据视图、读写/轮询配置及从站 JSON 编辑导入保存；视图通过 QWidget 容器挂载。
- 工作区保存会话、设备、轮询、会话通信参数、布局和外部文件引用；确定相对路径基准及配置版本规则。
- 保存无法加载插件的原始配置，启动错误定位到插件、设备或文件；后续 QML 绘图仅保留嵌入能力，不实现绘图功能。

## 验收条件

- [ ] 主站读写/轮询和从站编辑/导入/保存均经协议操作入口，界面不直接访问串口。
- [ ] 打开工作区只恢复配置，通信由用户启动；从站依赖外部 JSON，无缺文件零值回退。
- [ ] 主站观测值与从站模拟数据不混淆；读取可重试，写入不重试；保存文件不发送设备写命令。
- [ ] 正常界面只显示必要信息，异常有可见提示并可展开原始来源；过期/丢失不会呈现为完整历史。
- [ ] 未加载插件配置、文件路径和布局保存后往返不丢失；另存工作区时引用规则有明确行为。
- [ ] 多会话同时运行、开始/停止及后台记录不让 GUI 同步等待通信或磁盘。

## 验证证据

用代表性的操作流程验证工作区往返、缺插件/缺 JSON、未保存修改提示和回溯；界面性能及完整联调在 08 记录。
