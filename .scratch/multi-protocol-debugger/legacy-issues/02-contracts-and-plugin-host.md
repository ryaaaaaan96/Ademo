# 02 建立公共契约、插件宿主与会话生命周期

Status: needs-triage
Stage: RTU
Dependencies: 01

## 目标

建立协议和传输的真实扩展位置，以最小插件验证能力声明、创建、停止与销毁，不把 Modbus 名称或寄存器模型写入主体。依据：[接口契约](../interface-contracts.md)、[ADR 0003](../../../docs/adr/0003-restart-loaded-extension-plugins.md)、[ADR 0004](../../../docs/adr/0004-protocol-owned-interaction-and-views.md)。

## 工作范围

- 根据 01 建立 CMake 工程与公共类型，明确插件 ID、配套版本、角色、支持组合和工厂契约。
- 实现会话配置、端点占用、运行/连接代次、异步启停及结果发布；视图工厂可选，协议可无界面运行。
- 用最小测试协议/传输 Adapter 验证对象所有权和事件顺序；它们只验证 SDK，不冒充真实 UPP。
- 实现缺失/不兼容/加载失败提示，保留无法解释的插件配置；运行期间不卸载插件。

## 验收条件

- [ ] 新增测试插件后通过描述和工厂接入，主体不增加按协议名称判断的代码。
- [ ] 兼容校验失败、重复 ID 和不支持组合有明确诊断，只影响相关能力/会话。
- [ ] 停止时不再接受新操作，取消计时、关闭端点并结束遗留操作；旧代次回调不能更新新会话。
- [ ] 创建/销毁视图和会话符合所有权约定，插件对象销毁前代码保持加载。
- [ ] 保留未加载插件配置的往返能力，并将验证后的接口修正同步回契约文档。

## 验证证据

从公开 Interface 测试正常加载、拒绝加载、启停与迟到回调；至少一次真实 DLL 加载与销毁验证，不能仅测模拟工厂。
