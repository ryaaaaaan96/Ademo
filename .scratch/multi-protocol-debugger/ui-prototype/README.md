# 多窗口界面原型：仅用于 UI01 确认

复用已有 Qt Widgets / QQuickWidget 原型，全部通信为模拟数据，不加载产品协议 DLL，也不打开串口、CAN 或网络。本目录不是正式产品实现；临时 JSON、256 行和四曲线等演示限制不作为正式规格。

本机已构建后，双击本目录的 **打开界面原型.cmd**。它使用已有 Qt/LLVM-MinGW 环境，绕过运行 PowerShell 脚本的需要；这是本机开发启动入口，不是独立便携交付包。窗口标题为“多协议调试工作台 · 界面原型（模拟数据）”，请与旧产品窗口区分。

需要重建时，由允许执行脚本的开发终端运行 run.ps1 -BuildOnly；截图运行用 run.ps1 -Capture。原型 build/ 和 runtime/ 均已忽略，演示文件仅写入 runtime/ 或由用户明确选择的保存位置。

## 建议操作顺序

1. 默认有两个独立模拟会话，初始均停止。比较顶部“左右平铺／上下平铺／独立浮窗”，拖动标题可放回主窗口；较小窗口可滚动查看内容。
2. 在主站窗口点击“启动”和“读取本组”，双击目标电压的值改成 230，再开始轮询：黄色待提交值应保持；点击本行“设置”才执行一次模拟写入。可切换“模拟：超时”观察不确定提示。
3. 切换设备或参数组，观察其他设备轮询继续；左侧“会话→设备”定位到所属窗口。每个窗口底部的记录随窗口移动。
4. 进入“文件编辑”，修改初始值并“保存文件”，切回参数页应没有隐式应用；再明确“加载／应用到该设备”。打开文件、另存为和设备设置是不同动作。
5. 选中同一设备的多个参数后“绘图”，再明确开始轮询。试用暂停显示、清空和缩放；打开曲线本身不启动采集。
6. 在从站窗口启动后双击模拟值，观察本地立即变化；“保存运行值到文件”与文件页草稿的保存/应用分开。关闭窗口会停止对应模拟会话，其他窗口继续；左侧选择会话可重新打开，保持停止。
