# 从站启动依赖外部数据文件

用户在 Q30 明确选择外部 JSON 作为模拟从站启动时的数据来源：工作区保存文件引用，启动时加载，文件缺失时不启动从站通信。这替代此前工作区可内嵌模拟数据快照的安排；不使用工作区副本或默认零值掩盖缺失的文件。

这一选择使启动数据由独立的从站数据文件维护，代价是转移工作区时也需要携带文件或重新指定引用。运行中改值以及校验成功的整份导入、地址范围调整立即作用于后续请求，保存负责将当前数据写回文件；一条协议请求使用一致的数据视图。

Q32 确认仅在启动会话或主动导入时读取文件，运行中的外部修改和删除不自动影响已加载数据。启动时该会话的必需文件全部有效才允许通信；缺失、无法读取或格式错误只阻止对应会话，界面和其他会话仍可使用。重新加载前有未保存修改时提示保存、放弃或取消。
