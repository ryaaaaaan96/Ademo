# 协议交互与专用视图归协议插件

仅扩展编解码不足以兑现“新协议通过插件接入，主体不修改”：如果配置项、按钮和专用数据页面写在主体中，每次新增协议仍需要修改主体。因此协议插件负责协议会话、编解码、配置与操作声明，以及可选的专用视图；主体负责会话生命周期、通道、记录和通用界面，并按插件能力挂载。

Modbus 寄存器视图属于 Modbus 插件，其他协议不必采用寄存器模型。代价是插件 SDK 需要规定视图的创建、模型访问和销毁边界；后续 [ADR 0006](0006-widgets-shell-with-optional-qml-panels.md) 已确定 Qt Widgets 宿主与可选 QML 面板的方案。
