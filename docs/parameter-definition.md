# Modbus 主站参数定义文件

UI04 引入独立的参数声明格式。它描述某个设备需要展示和读取的地址，不包含设备观测值，也不包含从站模拟值。文件可复用于不同设备；应用目标由界面的“设备地址”明确指定，文件不能改变串口端点或设备地址。

```json
{
  "kind": "modbus-parameter-definition",
  "version": 1,
  "parameters": [
    {
      "area": "holding",
      "address": 107,
      "name": "出口温度",
      "type": "uint16",
      "unit": "°C",
      "description": "未经比例换算的寄存器原值",
      "group": "测量"
    },
    { "area": "coils", "address": 0, "type": "bool" }
  ]
}
```

`kind` 和整数 `version=1` 必填。`parameters` 为数组，可以为空；每项必须有 `area` 和整数 `address`。同一文件不能重复同一数据区与地址。设备、数据区及地址共同形成运行中的稳定参数身份。

| 字段 | 规则 |
| --- | --- |
| area | coils、discrete、holding、input |
| address | 零起始 PDU 地址，整数 0..65535 |
| type | 可省略；coils/discrete 为 bool，holding/input 为 uint16，当前不进行跨寄存器合并或比例换算 |
| name | 可省略；缺失或空字符串时显示 PDU 地址 |
| unit | 可省略；显示单位文本，不是设备地址 |
| description | 可省略；缺失时显示对应数据区 |
| group | 可省略；缺失或空字符串进入默认组 |

字符串字段最多 1024 字符，文件最多 1 MiB，每个设备最多 4096 个参数。这是本次有界 Widgets 表格和文件读取预算，不改变 Modbus 地址范围，也不是原型的 256 行限制；验收覆盖 257 行生成。按地址生成范围时先检查末地址和设备参数容量，失败不添加部分行。重复地址保留已有参数的名称和分组。

## 加载与运行边界

先停止目标会话，在参数页填设备地址，选择文件，再点击“加载并应用到设备”。选择文件或修改路径不应用。后台完整读取和校验成功后，替换指定设备的参数声明；其他设备保留。加载不发送读写请求、不自动启动会话。每行“读取”经现有会话和 Modbus 插件执行；切换设备或分组只改变显示。

界面会捕获点击时的目标设备和路径。读取期间若会话被启动，配置入口拒绝应用并保留原参数；关闭视图后结果不会写回。外部编辑或删除文件不热加载，必须由用户再次明确加载。格式错误、缺失文件、重复地址、不支持类型和容量错误均保留当前内容。

## 现有配置与文件兼容

- 旧从站数据文件及 `protocol.devices[*].path` 语义完全保留；参数定义不能作为从站启动数据。旧从站仍要求全部外部数据文件有效，不以工作区内容兜底。
- UI02 的 `protocol.parameterRows` 地址行继续可读。UI04 增加 name/type/displayUnit/description/group 元数据；旧行没有这些字段时使用地址、默认类型和默认组。
- `protocol.parameterFiles` 是设备地址字符串到来源路径的映射。工作区保存时转为相对路径，恢复时解析为绝对路径；插件缺失时由既有工作区的不透明配置机制保留。
- 工作区中的 parameterRows 是上次明确应用的主站参数声明，不是设备值或从站模拟数据。恢复声明不读取或热加载来源文件，因此之后外部文件改变不会悄悄改写工作区已应用的参数；来源文件缺失时仍可按保存的地址调试，重新加载会明确报错。
- 文件保存和编辑留给 UI07；本切片没有“保存即应用”或设备写入入口。

## 插件后台文件任务

SDK10 的 `SessionAccess.background(work, completion)` 允许尚未启动的参数视图请求后台值任务。它与既有本地文件任务共享最多 4 个任务的额度，忙时返回 false；work 只处理值，completion 回到会话线程，异常作为 error 字段返回。宿主保留插件目录租约直到任务、回调及其中的插件函数释放；会话销毁后不调用 completion。视图回调还须使用 QPointer 检查自身存活。

后台能力始于 SDK10；UI05 为多视图修改保护将 SDK、IID 和构建指纹升级到 11，配套协议与传输 DLL 必须一起重编并重启。UI07 可复用本入口；它不负责隐式配置应用、文件保存或设备通信。
