# 从站参数操作与文件编辑

连接配置选择 `slave` 后，插件挂载从站参数页。角色变更须先处理原页面的修改；取消保留原角色、页面与运行值。主体只按插件工厂及当前角色重新挂载，不解释 Modbus 字段。

## 启动与设备

在停止状态下用“添加模拟设备”添加 1..247 地址及启动文件路径；同地址更新绑定。一个会话最多 32 个设备，设备文件必须独立。也可暂时留空路径，进入文件编辑页创建数据、保存外部 JSON，再明确应用启动绑定。未加载时不会以空表或默认值启动：启动继续调用既有后台全量校验，任一必需文件缺失或无效只阻止此会话。

设备导航在启动前就显示配置设备。启动后参数页显示本地模拟数据；选择设备、数据区或文件页不停止通信。四数据区保留原 0..65535 地址范围；表格每页最多显示 256 项，通过“显示偏移”浏览整个范围，256 是渲染页大小而非模拟容量上限。

## 运行值和文件草稿

| 动作 | 来源与结果 |
| --- | --- |
| 参数表双击“值”后提交 | 完整布尔值或 0..65535 整数校验后立即更新本地模拟值，影响后续请求；无效输入、Escape 取消保留原值，不形成主动设备写入。 |
| 保存运行值 | 明确确认后调用既有 `slave-save`，保存操作开始时的运行快照。保存中新收到的外部写入继续生效并保持未保存标记；文件编辑草稿保持原样。可填新路径另存并绑定。 |
| 文件页编辑／保存／另存 | 来源为编辑页独立快照；保存只写外部 JSON，不清除运行值修改，也不应用或发送。覆盖已有文件需要确认，不能覆盖另一设备绑定的文件。 |
| 文件页应用 | 未启动且无运行数据时更新外部启动文件绑定；已有运行数据时通过原 `slave-import` 完整读取、校验和原子替换目标设备。其他设备不变，通信继续。 |
| 文件页打开 | 后台读取到编辑页，不应用。磁盘文件不会热加载到运行数据。 |

应用传递编辑页确认的 `expectedDocument`；磁盘内容若在打开／保存后改变，协议文件任务拒绝替换并要求重新打开，避免“界面显示 A、实际应用 B”。未保存运行值提示提供保存、放弃、取消。选择保存可能改写原绑定文件；若它同时是编辑页来源，内容核对会阻止继续应用过期快照。文件任务结果显示在参数操作页，不把任务已提交当作应用完成。

文件编辑器保留根对象和数据区未知字段，直接复用正式 version=1 四区从站格式。可编辑各区起址、数量和逐项数值，无需手写 JSON。空区允许保存；越界范围和错误值不能保存或应用。单设备文件保持旧 **4 MiB** 上限、整个会话 **16 MiB**，并以紧凑 JSON 保存，避免缩进膨胀使原先可用内容无法往返。

## 修改与生命周期保护

文件页的草稿、后台任务和模态窗口使用 UI07 的独立 owner 守卫。运行值由从站新视图提供会话守卫，兼容旧操作页不覆盖它。所有确认使用堆对话框和 QPointer，并持有 SDK12 GUI 租约；设备与角色下拉框先退出信号发送栈再执行可能销毁页面的保护，过期排队选择失效。

运行值提示期间若出现新修改，本次放弃／应用／保存确认不再有效，原数据保留。关闭或变更角色时选择保存会发起后台文件任务；等待保存完成后再次执行关闭／切换，若期间又有新写入会继续提示。停止只停止通信，运行值仍可查看、编辑和保存。

本页复用已有 RTU 通信、外部文件和记录服务。本切片的可控传输与原生 Qt 测试不代表真实串口／独立对端验收；旧13仍待硬件，旧14–19未启动。
