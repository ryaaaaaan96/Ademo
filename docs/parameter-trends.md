# 参数趋势

在主站参数操作页选择同设备的数值寄存器参数，点击“绘制选中参数”。曲线窗口采用 QMainWindow 系统最小化、最大化和关闭按钮，白底 QQuickWidget 实际加载资源中的 QML。打开窗口只订阅会话已有消息；连续采集由参数页的“开始轮询”显式启用。

图例显示名称和真实单位，概要同时显示设备/数据区/PDU 地址、最后显示值和样本数量。不同曲线使用不同颜色，取消勾选可隐藏对应曲线。Y 轴为共同的实际数值尺度，不逐条归一化；不同单位仍由图例标明，不进行隐式换算。X 轴显示相对最新样本的秒数，默认最近 60 秒，放大/缩小范围为 1–3600 秒。

“暂停显示”冻结图形和显示值，通信、参数表及有界样本缓冲继续更新；恢复显示会跟上缓冲区。“清空曲线”只清除当前图形，连尚未进入刷新周期的旧消息也越过，不删除协议消息、运行参数或原始通信记录。暂停时仍可清空、缩放和切换图例。

## 边界与容量

- `plugins/master_trends.cpp` 固定捕获会话访问入口及 unit/area/address，切换设备、分组和页面不会改变已有曲线身份。仅接受 `success`、`operationResult=true`、`freshnessUncertain=false` 的数值；异常、无归属响应和超时后的不确定候选值不作为采样。
- 协议适配器每 100 ms 读取会话的既有有界消息窗口，以消息 ID 去重。它不发送请求。显示刷新同样由 100 ms 定时器合并，仅在内容变化时提交 QML。输入快于会话消息保留窗口时可能略过已淘汰消息；趋势是有界观察窗口，不是无损记录器，完整记录继续使用既有归档功能。
- 每条曲线最多保留 2048 个最新样本，每窗口最多 32 条曲线，每会话最多 8 个趋势窗口。超过窗口/曲线容量明确提示并拒绝打开，不静默截断。容量是基于正式实现的有界内存与刷新预算，并由实际 RTU 公开入口负载测试验证，不继承原型四曲线或 256 行限制。
- `debugger_widgets` 中的 TrendWindow 只接收已经解释的数值，QML 不访问端口或协议。图形原生 owner 为外层工作台，所属 ParameterView 销毁时关闭图形；SessionWindow 浮动/停靠不重新 parent QQuickWidget，避免重建交换链。
- SDK12 中，适配器回调随 SessionAccess 持有插件租约，所属视图销毁回调先复制 `access.lifetime` 再删除图形，保护计时器闭包释放后的 DLL 返回栈。与文件页一样只在 GUI 线程使用该租约。

## 构建与验证

沿用 Qt 6.12.0 / LLVM-MinGW 22.1.7 和 `qt-llvm-debug`、`qt-llvm-release` presets；新增已有 Qt QuickWidgets 组件，QML 使用 QtQuick，资源随 Modbus 配套 DLL 嵌入。独立部署时还需交付对应 Qt Quick/QML 运行库及 QtQuick QML import；不要只复制 exe。

`parameter_qml_trends` 测试经真实 ParameterView 按钮打开 QQuickWidget，验证 Ready/可读 framebuffer、暂停/图例/缩放/清空、设备隔离、来源过滤、容量和原生窗口生命周期。系统边界使用可控 Endpoint 与时钟，协议实现是真实 RTU。Windows 可见测试结果及截图见 UI10 验收证据；该自动化证据不代替真实硬件与 UI13 人工产品验收。
