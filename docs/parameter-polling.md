# 参数读取与轮询

参数操作页支持行内读取、读取选中项、读取当前组，以及选择范围和周期后开始轮询。它们共用原有 RTU 会话和总线队列，不创建额外串口连接。

- 选中项和当前组都仅针对当前设备、当前组。只有同设备、同数据区、地址连续的参数才合并，不跨越未选地址。每次读取按照线圈／离散输入 2000 位、保持／输入寄存器 125 字的协议上限拆分。
- 一次界面批量读取最多形成 64 个独立请求，超过时整体拒绝，不先发送一部分。总线已有任务时仍可能达到既有队列容量，拒绝通过操作结果显示。
- 轮询范围选择“选中项”或“当前组”，周期为 10..3600000 ms。点击开始时捕获目标；切换设备、分组、页面或窗口不改变这些目标。界面列出所有已配置任务的设备、数据区、地址和周期。
- 再次开始会更新当前设备当前组的轮询范围，其他设备／组和旧配置中的独立任务保留。会话最多 64 个轮询请求，超限保留旧配置；在途或排队任务未结束时沿用原配置保护，显示忙碌原因，用户可在空闲后重新开始。
- “停止会话轮询”停止本会话所有后续轮询，不关闭端点，也不取消已经接受的手动请求或在途读取。已在途读取的超时、重试及最终响应归属继续按原规则处理。
- 轮询只生成读取。设备写入仍须点击行内设置，不被自动轮询或重试。读回更新不会覆盖活动编辑器和黄色待提交值。

工作区继续保存原有 `polls` 配置数组。参数页产生的任务额外带有 `area` 和 `parameterGroup`，用以显示目标并在明确再次开始时识别所属参数组；调度仍使用 `unit/action/start/count/intervalMs`。旧任务没有 `parameterGroup` 时作为独立任务保留。没有新增文件版本或改变已有轮询启动／重连规则。

新增 `stop-polling` 为 RTU 主站会话的本地调度操作，不发送 Modbus 帧。其使用运行实例已校验的配置清空 `polls`，不接受调用者传入的替代配置，避免停止动作改变重试、参数或文件引用。`configure-polling` 的原有忙碌保护和读取重试语义保持。

## 读取重试和按功能码操作

正式参数页点击“配置…”后，通过“读取重试配置…”单独调整额外读取重试、应答超时与重试间隔，应用时保留完整现有轮询任务和其他协议配置。打开不通信，运行中仍遵守 `configure-polling` 忙碌保护。停止状态保存在会话配置中，下次启动生效。

轮询范围、周期和会话任务明细位于同一配置窗口，主页面仅显示简短摘要以及开始／停止按钮。修改范围和周期是准备下一次操作，不立即替换正在运行的任务；返回参数页点击“开始轮询”时才捕获当前选区和设备／分组。关闭配置窗口保留这些输入，既不启动也不停止通信。

“按功能码操作…”提供四区范围读取及 05/06/0F/10 写入，与参数页共用同一会话。这里不另建观测、轮询或记录面板，结果只跟踪该窗口明确提交的操作。线圈输入布尔、寄存器输入整数，多值使用 JSON 数组；非法输入不发送。用户编辑的写入输入参与窗口/会话关闭保护，取消保留内容，放弃不撤回已发送报文。所有写入不自动重试；未确认输入和不确定结果不被其他轮询结果覆盖。
