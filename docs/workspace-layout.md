# 工作区窗口布局

工作区仍采用 version=1。保存／打开继续通过后台有界文件任务，保存的是会话配置与外部文件引用，不包含从站运行值、主站待提交值或文件编辑草稿。打开成功后所有会话保持停止；缺失从站文件仍会在显式启动时阻止该会话，其他会话可独立启动。

## 布局往返

| 位置 | 字段 | 含义 |
| --- | --- | --- |
| 根 layout | geometry、dockState | Qt 的 Base64 窗口几何与停靠排列，包含分割位置；由配套 Qt 保存和恢复。 |
| 根 layout | activeSession | 当前会话索引，恢复不会因此重新打开已关闭窗口。 |
| sessions[].layout | floating、open | 独立浮窗／停靠状态，以及窗口是否打开。关闭配置仍保留。 |
| sessions[].layout | windowGeometry | 浮窗原生位置、大小及 Qt 几何状态。 |
| sessions[].layout | selectedDevice | 插件给出的不透明设备 ID；无法选择时保留插件默认选择。 |
| sessions[].layout | scrollX、scrollY | 原有参数内容滚动位置。 |

旧工作区没有这些可选字段时，沿用旧默认行为；未知根、会话、配置及布局字段继续往返保存。缺失插件的配置与引用基准不由宿主解释，修复插件后仍可恢复。

已保存几何优先于新建浮窗的居中位置，即使工作区在主窗口首次显示前打开也如此。Qt 几何恢复会将已离线屏幕或远离当前桌面的窗口放回可见范围；本机验证覆盖离桌面坐标恢复，多物理显示器切换仍需相应桌面环境检查。

## 仅恢复布局

工具栏“恢复已保存布局”使用最后一次成功打开或保存的排列，只重排现有窗口。当前会话对象、窗口开闭、设备选择、数据和通信不变；它不会重载文件，也不会按旧的关闭状态停掉已重新运行的会话。新增但尚未保存的会话保留，完整打开工作区才恢复文件记录的配置和开闭状态。

## 失败与修改保护

布局布尔值、设备 ID 类型和有界 Base64 先随文件校验；Qt 几何与停靠数据还会在 GUI 线程的临时窗口上试恢复。失败在当前会话的修改提示与清空之前报告 file-error，避免半替换或已经通信的会话被无效布局停止。

有效工作区替换复用主站待提交值、文件草稿、从站运行值的独立保护；取消保留原会话。后续会话提示期间，较早会话若出现新写入或后台任务，提交替换前的二次检查会取消整个替换，保留新增数据。工作区选择器打开期间，早先后台加载也不能替换当前会话；关闭选择器后可明确重试。

工作区文件选择使用堆对话框与 QPointer，父窗口在模态循环中被销毁时安全返回。此能力与 SDK12 插件 GUI 租约配合，不扩展插件热加载或跨线程 QWidget 访问范围。
