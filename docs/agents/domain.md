# 领域文档

## 探索前读取

- 根目录的 `GLOSSARY.md`：读取与当前主题有关的术语。
- `docs/adr/`：读取涉及当前工作范围的架构决策记录。

文件尚不存在时，直接继续工作。术语和决策明确后，由 `domain-modeling` 技能按需创建文档。

## 布局

本项目采用 single-context 布局：

```text
/
├── GLOSSARY.md
└── docs/
    └── adr/
        └── 0001-<decision-slug>.md
```

## 术语

在 issue 标题、重构建议、假设和测试命名中，使用 `GLOSSARY.md` 定义的领域术语。遇到未定义的概念时，先检查现有项目用语；确有缺口时记录为后续领域建模事项。

## 决策冲突

输出与已有 ADR 冲突时，明确指出具体 ADR、冲突内容以及重新讨论的理由。
